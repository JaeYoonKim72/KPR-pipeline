# Step 5: Population genetics of AMY flanking regions

Script: [`5.Population_genetics_in_AMY_flanking_locus.sh`](5.Population_genetics_in_AMY_flanking_locus.sh)

This is the **locus-level flanking analysis**, distinct from the graph-based
AMY structural analysis in step 4. All input calls are assumed to be diploid,
phased, **biallelic SNPs** on GRCh38. No independent AMY gene-copy/paralog
SNP analyses are performed.

## Why distal and proximal flanks?

AMY1A/AMY1B/AMY1C and AMY2A/AMY2B belong to a structurally variable region
(SVR) with highly similar duplicated copies and gene conversion. Their
paralog-specific alleles cannot generally be interpreted as independent
short-read diploid loci. We therefore evaluate flanking sequence variation
at the **AMY locus level** rather than claiming per-copy nucleotide diversity,
FST, or LD.

The GRCh38 flanks follow **Bolognini et al. (2024)**, *Recurrent evolution
and selection shape structural diversity at the amylase locus*,
Nature, https://doi.org/10.1038/s41586-024-07911-1 .
We use the published **bundle 0** and **bundle 1a** coordinates without
shifting them. These coordinates are the defaults, **not immutable constants**:

| Region | GRCh38 1-based inclusive | Length |
|---|---|---:|
| Distal (bundle 0) | chr1:103,456,163–103,561,526 | 105,364 bp |
| Excluded middle (SVR) | chr1:103,561,527–103,760,697 | 199,171 bp |
| Proximal (bundle 1a) | chr1:103,760,698–103,826,698 | 66,001 bp |
| Entire span for exclusion from backgrounds | chr1:103,456,163–103,826,698 | 370,536 bp |

Use `--distal chr1:START-END --proximal chr1:START-END` (or environment
`DISTAL` and `PROXIMAL`) to override the defaults. For the published
analysis, retain these defaults.

## Software and activated environment

Require Bash, Python 3 and `bcftools` for focal diversity, LD and FST.
`selscan v3.0.1` is an **optional dependency for unphased nSL and phased
XP-nSL**. Install it with mamba or conda and **activate the environment before
running the shell script**:

```bash
mamba create -n amy_popgen -c conda-forge -c bioconda selscan=3.0.1 bcftools python
conda activate amy_popgen
selscan --version
```

If the installation recipe is unavailable for a particular platform/channel,
use a separately installed selscan v3.0.1 binary on `PATH`.
The pipeline **does not install software automatically**. On `all`, when
v3.0.1 cannot be found, the script warns with the installation command,
marks nSL/XP-nSL `SKIPPED_MISSING_SELSCAN`, and runs diversity, LD,
across-LD and Hudson FST.

## Input

Supply **one joint multi-sample, indexed, coordinate-sorted phased VCF**
(`VCF`), with exactly one allele pair (REF, ALT) per biallelic SNP. The
chromosome contig should match the default `chr1` (override intervals if the
VCF uses `1`). FORMAT should contain diploid `GT` as its first field.
Provide one plain-text list of sample IDs per population, with one sample
per line. Lists must be disjoint and samples must exist in the VCF. The
**first** population is the query for all pairwise comparisons.

Use the GRCh38 1000 Genomes StrictMask (20160622; BED, 0-based half-open)
as `CALLABLE_BED` / `--mask`, optionally intersected with non-N reference
regions before input. Without a mask, the first-stage script explicitly
warns and divides by the **physical flank length**, not the corresponding
callable length; those results should not be described as StrictMask-adjusted.

## Quick start

```bash
export VCF=/path/to/joint.phased.biallelic.snps.vcf.gz
export POPS="KOR=/path/to/KOR302.samples CHN=/path/to/CHN.samples JPT=/path/to/JPT.samples"
export CALLABLE_BED=/path/to/GRCh38.StrictMask.20160622.bed.gz
export OUT_DIR=/path/to/results/amy_popgen

bash 5.Population_genetics_in_AMY_flanking_locus.sh all
```

Equivalent command-line form:

```bash
bash 5.Population_genetics_in_AMY_flanking_locus.sh all \
  --vcf /path/to/joint.phased.biallelic.snps.vcf.gz \
  --pop KOR=/path/to/KOR302.samples \
  --pop CHN=/path/to/CHN.samples \
  --out /path/to/results --mask /path/to/StrictMask.bed.gz
```

Using a **single** `--pop` computes diversity, within-LD, across-LD and
nSL only. Supplying 2+ populations additionally computes each non-first
population's FST and XP-nSL against the **first** population. No parallel
jobs are launched by this wrapper.

## Steps and output

| Step | Primary output | Definition |
|---|---|---|
| `diversity` | `stats/diversity.tsv` | π per bp; Watterson θW using expected projected segregating sites (default n=168 allele copies); descriptive projected Tajima D |
| `ld` | `stats/within_ld.tsv` | Mean sample-size-corrected dosage Pearson r²; distal pairs <100 kb; proximal pairs <60 kb |
| `across_ld` | `stats/across_ld.tsv` | Mean corrected dosage r² across **all** valid distal × proximal SNP pairs (no 370-kb SNP-pair cutoff) |
| `fst` | `stats/hudson_fst.tsv` | Hudson FST ratio of summed site numerators and denominators, retaining negative estimates |
| `nsl` | `selscan/*.nsl*; status.tsv` | Unphased nSL, MAF≥0.05 core threshold; keep low-frequency extension SNPs; maximum 50 markers |
| `xpnsl` | `selscan/*.xpnsl*; status.tsv` | Phased XP-nSL on shared matched POS/REF/ALT SNPs, same extension cap |
| `all` | all above | Runs each applicable analysis, skips optional missing selscan |

Per-group genotype call rate ≥90% is applied in the focal Python
calculations. Site-wise π uses observed allele counts; θW projects the
allele frequency spectrum to `PROJECTION_N` copies. The Tajima D in the
first-stage helper is a **descriptive plug-in approximation** using projected
E[S] and cannot be treated as a calibrated neutrality-test statistic.

The included [`hudson_fst.py`](hudson_fst.py) was originally designed for
copy-level VCFs from the older graph script, and is not used for AMY flanking
comparisons here. The new helper reproduces the same ratio-of-sums estimator,
but restricts to focal flanks and shared valid callable SNPs.

## Crucial statistical limits of this first-stage implementation

The first-stage script produces **AMY focal point estimates**. It is not an
automatic reproduction of every confidence interval, enrichment ratio or
genomewide percentile shown in Supplementary Tables X1, X2 and X3.

- **Genomewide comparisons**: 1-kb sliding genomic windows, genomic upper-tail
  ranks, distance-matched LD enrichment, autosomal 5-Mb block bootstraps
  (10,000 replicates) are not produced.
- **Sampling intervals**: per-person 10,000-replicate bootstrap, individual
  jackknife and 93:93 XP-nSL subsampling are not produced.
- **selscan normalization**: raw focal selscan scores are written; they are
  explicitly marked `RAW_ONLY`. Proper Methods-equivalent normalized
  nSL requires autosomal chr2–22 allele-frequency-bin background fitted
  with `selscan norm --nsl --bins 100`; XP-nSL also requires genomewide
  background normalization for the same query/reference comparison.
  **Do not interpret focal raw scores as normalized mean |nSL| or
  normalized XP-nSL scores.**
- **Tajima D**: requires verification against the final projected-frequency
  pipeline before publication; the present plug-in value is exploratory.
- **Performance**: `amy_flank_popgen.py` reads VCF records in Python and
  uses direct SNP-pair loops. Use a variant-filtered joint chr1 VCF; not
  a whole-genome compressed VCF for this first-stage helper.

For the GigaScience revision, final manuscript values must come from the
separately verified full cohort, background, and resampling analysis.
Do not substitute this simplified runner's exploratory numbers for the
validated X1/X2/X3 tables.
