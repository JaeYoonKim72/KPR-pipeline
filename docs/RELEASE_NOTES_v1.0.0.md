# KPR-pipeline v1.0.0

Computational pipelines for the construction and characterization of the Korean Pangenome Reference (KPR), accompanying the study *Constructing a Korean pangenome reveals distinct haplotypes at the amylase locus*.

## Included workflows

1. Sample selection, genome assembly, quality assessment, repeat annotation and structural variant detection
2. Ensemble gene annotation and copy-number gain analysis
3. Pangenome construction, graph statistics, growth curves and non-reference sequence analysis
4. Locus- and allele-level variant comparisons
5. Variant benchmarking and Mendelian genotype inheritance inconsistency
6. Short-read mapping and variant calling
7. AMY structural haplotype analysis
8. AMY flanking-region population genetics

The [README](../README.md) links to the documentation for each pipeline, including software requirements, input preparation, analysis parameters, execution commands and outputs.
