# pangenome_short_read_mapping.sh

Short-read mapping to the pangenome graphs and graph-based variant calling,
with a linear GRCh38 baseline for comparison.

Part of the [KPR-pipeline](README.md) repository.

Reads are mapped with `vg giraffe`, projected onto the coordinates of the
linear reference embedded in the graph with `vg surject`, and used for small
variant calling with DeepVariant. Structural variants are genotyped directly on
the graph with `vg pack` and `vg call`. The same samples are also mapped to
GRCh38 and called with DeepVariant, Manta and Delly, so the references can be
compared.

---

## 1. Set up

### 1.1 Software

Install the tools listed under [Software](#software) and make sure they are on
`PATH`. DeepVariant runs from a container image, so a container runtime is
needed as well.

### 1.2 Pangenome graphs

`GRAPH_DIR` holds one subdirectory per reference, named after the graph. Each
subdirectory holds the files produced by
[`pangenome_construction_and_statistics.sh`](pangenome_construction_and_statistics.md):

```
graphs/
├── kpr/
│   ├── kpr.gbz        graph used by vg giraffe, vg pack and vg call
│   ├── kpr.xg         graph used by vg surject and vg paths
│   ├── kpr.hapl       haplotype index used for haplotype sampling
│   └── kpr.snarls     snarls used by vg call, generated by step 1 if absent
├── hprc/
└── hprc_kpr/
```

The HPRC graph is the published `hprc-v1.1-mc-grch38` graph, renamed to match
this layout.

### 1.3 Reads and sample list

FASTQ files go in `DATA_DIR`, named by sample ID:

```
SAMPLE_1.fastq.gz  SAMPLE_2.fastq.gz
```

`LIST_DIR/samples.list` holds one sample ID per line.

### 1.4 Reference

`GRCh38.fa` in `REF_DIR`, indexed with `samtools faidx` and with a `bwa-mem2`
index, is used by the baseline step only. The reference used for calling on
each pangenome is extracted from the graph itself in step 1.

### 1.5 Environment

```bash
export DATA_DIR=/path/to/fastq        # required
export REF_DIR=/path/to/reference     # required
export GRAPH_DIR=/path/to/graphs      # required
export OUT_DIR=/path/to/results       # default: ./results
export LIST_DIR=/path/to/lists        # default: ./lists
export THREADS=8
```

## 2. Run

Print the available steps:

```bash
bash pangenome_short_read_mapping.sh
```

Run everything in order:

```bash
bash pangenome_short_read_mapping.sh all
```

Run one step at a time, which is what we recommend:

```bash
bash pangenome_short_read_mapping.sh prepare_reference
bash pangenome_short_read_mapping.sh read_prep
bash pangenome_short_read_mapping.sh kmer_index
bash pangenome_short_read_mapping.sh giraffe
```

Evaluate a single reference by restricting `GRAPHS`:

```bash
GRAPHS=kpr bash pangenome_short_read_mapping.sh giraffe
GRAPHS="kpr hprc" bash pangenome_short_read_mapping.sh sv_variants
```

Override individual settings on the command line:

```bash
THREADS=16 bash pangenome_short_read_mapping.sh giraffe
MIN_DP=10 MIN_GQ=20 bash pangenome_short_read_mapping.sh classify
```

Mapping and calling are per sample, so on a cluster the natural unit of
parallelism is a subset of the sample list:

```bash
split -l 1 lists/samples.list lists/part_
for P in lists/part_*; do
  qsub -N "$(basename "$P")" -pe smp 8 -V -cwd \
    -b y "SAMPLE_LIST=$P bash pangenome_short_read_mapping.sh giraffe"
done
```

Every step writes to `$OUT_DIR/logs/pipeline.log` and skips a reference whose
input files are missing, so a step can be rerun after fixing a problem without
repeating the others.

## 3. Steps

| Step | Description |
|---|---|
| `prepare_reference` | Reference paths, FASTA, dictionary, contig rename table and snarls, extracted from each graph |
| `read_prep` | Read name clean-up and per-sample read lists |
| `kmer_index` | kmc k-mer index used for haplotype sampling |
| `giraffe` | Read mapping to the pangenome graph, output in GAF |
| `surject` | Projection of the alignments onto the linear reference |
| `bam_cleanup` | Coordinate sorting, duplicate removal and indexing |
| `small_variants` | DeepVariant calling, PASS filtering, contig renaming |
| `sv_variants` | `vg pack` and `vg call` genotyping, PASS filtering |
| `classify` | Classification into SNP, bi-allelic SNP, indel and SV, genotype filtering and counting |
| `grch38_baseline` | Alignment, DeepVariant, Manta and Delly against GRCh38 |
| `all` | All of the above, in order |

Dependencies between steps: `giraffe` needs `read_prep` and `kmer_index`;
`surject` needs `giraffe` and `prepare_reference`; `bam_cleanup` needs
`surject`; `small_variants` needs `bam_cleanup`; `sv_variants` needs `giraffe`
and `prepare_reference`; `classify` needs `small_variants` and `sv_variants`.
`grch38_baseline` only needs `read_prep`.

## 5. What the steps do

### Reference preparation

The linear reference is taken from the graph rather than from a separate file,
so that the contig names of the alignments, of the reference FASTA and of the
called variants all agree. `vg paths -S GRCh38 -F` writes the sequence of the
reference paths as `GRCh38.fa`, and the list of path names is used as the
projection target of `vg surject`. A rename table maps the path names of the
graph (`GRCh38#0#chr1`) to plain chromosome names (`chr1`), which is applied to
the VCF files after calling. Snarls are generated with `vg snarls` if the graph
directory does not already contain them.

### Mapping

`kmc` counts the k-mers of each sample and writes a KFF file. `vg giraffe` uses
it together with the haplotype index to sample the haplotypes of the graph that
are relevant to the sample before mapping, which reduces both run time and
reference bias. Alignments are written in GAF, the graph-native format, and
kept: the small variant branch projects them onto the linear reference, while
the structural variant branch genotypes them on the graph directly.

### Small variants

`vg surject` converts the graph alignments to BAM in the coordinates of the
reference paths. After sorting, duplicate removal and indexing, DeepVariant
v1.6 calls small variants. The calls are restricted to PASS sites, the contigs
are renamed, and a second file without homozygous reference genotypes is
written.

The BAM post-processing performed in the study is not reproduced here; the step
provides a minimal equivalent that yields a sorted, deduplicated and indexed
BAM, and any samtools or Picard workflow with the same result can be
substituted.

### Structural variants

`vg pack` computes the read support of every node and edge from the GAF file,
with a mapping quality threshold of 5. `vg call` then genotypes the bubbles and
the alternative paths of the graph against the reference sample. The calls are
restricted to PASS sites, the header is aligned with the reference index, and
two further files are written, one without homozygous reference genotypes and
one without missing genotypes either.

### Classification

Each call set is split into SNPs, bi-allelic SNPs, indels of at most 50 bp and
structural variants longer than 50 bp, and the structural variants are split
into insertions and deletions. Every resulting file is then filtered on
genotype depth, genotype quality and site quality, and its records are counted
into a single table per reference.

## 6. Output

```
results/
├── reads/                cleaned FASTQ files and read lists
├── kmer_index/           per-sample KFF files
├── reference/            per-graph reference FASTA, index, dictionary, paths
├── gaf/                  graph alignments
├── bam/                  surjected, sorted and deduplicated alignments
├── small_variants/       DeepVariant calls, PASS and NoZero sets
├── structural_variants/  vg pack and vg call output, PASS and NoZero sets
├── variant_classes/      classified and filtered call sets, count tables
├── grch38/               linear reference baseline
└── logs/
```

Main tables:

- `variant_classes/GRAPH.variant_counts.tsv` — number of records in every
  classified and filtered call set, per reference
- `small_variants/GRAPH/GRAPH.SAMPLE.PASS.vcf.gz` — small variants
- `structural_variants/GRAPH/GRAPH.SAMPLE.sv.PASS.vcf.gz` — structural variants
- `grch38/small_variants/`, `grch38/sv/` — the linear reference baseline
